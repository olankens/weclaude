name: readme-description
description: Generate or update the project description in README.md
---

Study the project and craft a description with these rules:

- Always begin with a capital letter and end with a period.
- Always ensure the text is grammatically correct and clean.
- Always fit the first 200 chars across 3 GitHub pin lines.
- Always fit the full description on 6 GitHub About lines.
- Always make the description at least 201 characters long.
- Always make the description at most 205 characters long.
- Always shorten the text when more capital letters appear.
- Never begin with a past tense verb or a gerund form here.
- Never include colons, semicolons, or em dashes in text.
- Never place a space or punctuation mark at character 197.
- Never start with an article, possessive, or demonstrative.
- Never use third-person singular verbs in the description.
- Never write product, project or person names in lowercase.

Replace the description in this block, keeping indentation:

```markdown
  <tbody><tr><td align="center" width="99999">&nbsp;<div>
    <!-- Description goes here -->
  </div>&nbsp;</td></tr></tbody>
```
